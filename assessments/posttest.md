C. ไม่รองรับ `response_format` แบบ JSON เลย
D. ต้องตั้ง `temperature` เป็น 2.0 เสมอ ไม่งั้นจะ error

### ข้อ 8
ใน Lab 3 (Streamlit) เหตุใดจึงต้องเก็บผลลัพธ์จาก AI ไว้ใน `st.session_state` แทนที่จะใช้ตัวแปรธรรมดาในบล็อกของปุ่ม (`if st.button(...)`)?

A. เพราะ Streamlit รันสคริปต์ทั้งไฟล์ใหม่ทุกครั้งที่ผู้ใช้โต้ตอบกับหน้าเว็บ ถ้าไม่เก็บไว้ใน session_state ผลลัพธ์ที่แสดง (เช่น dropdown ให้แก้ไข) จะหายไปเมื่อผู้ใช้โต้ตอบกับ widget อื่นก่อนกด submit
B. เพราะ session_state ทำให้โปรแกรมรันเร็วขึ้นเท่านั้น
C. เพราะ Streamlit ไม่อนุญาตให้ใช้ตัวแปรธรรมดาเลย
D. เพราะต้องการลด token cost ของ API

### ข้อ 9
ใน Lab 4 การประมวลผลข้อมูลจำนวนมากด้วย Pandas เหตุใดโค้ดจึงต้องใช้ทั้ง `try-except` และ `time.sleep()` ร่วมกัน?

A. `try-except` ป้องกันโปรแกรมพังกลางคันเมื่อบางแถวเรียก API ผิดพลาด ส่วน `time.sleep()` ช่วยไม่ให้ยิง request ถี่เกินไปจนชน Rate Limit (429 Too Many Requests)
B. `try-except` ใช้เพื่อเพิ่มความเร็ว ส่วน `time.sleep()` ใช้เพื่อลด token
C. ทั้งสองอย่างมีไว้เพื่อแปลง JSON เป็น Excel เท่านั้น
D. เพื่อให้ไฟล์ Excel มีสีสันสวยงามขึ้น
