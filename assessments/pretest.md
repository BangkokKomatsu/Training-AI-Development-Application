# Pre-test — AI Application Development: Mini AI Agent ด้วย Microsoft Foundry

> ทำแบบทดสอบนี้**ก่อน**เริ่มคอร์ส เพื่อวัดความรู้พื้นฐานก่อนเรียน (ไม่มีผลต่อคะแนน ตอบตามความเข้าใจปัจจุบัน)
> จำนวน 10 ข้อ ข้อละ 4 ตัวเลือก เลือกคำตอบที่ถูกต้องที่สุดเพียงข้อเดียว

### ข้อ 1
Large Language Model (LLM) คืออะไร?

A. โปรแกรมคำนวณตัวเลขและสถิติเพื่อทำนายแนวโน้มในอนาคต
B. โมเดลภาษาขนาดใหญ่ที่ถูกฝึกให้อ่าน/เขียนภาษาได้ใกล้เคียงมนุษย์ เช่น ตระกูล GPT
C. ฐานข้อมูลสำหรับเก็บ log การทำงานของเครื่องจักร
D. โปรแกรมสร้างหน้าเว็บแบบอัตโนมัติ

### ข้อ 2
ข้อแตกต่างหลักระหว่างการใช้ **Web Chat (เช่น ChatGPT)** กับการเรียกใช้ **API** คือข้อใด?

A. Web Chat เร็วกว่า API เสมอ
B. API ใช้ได้เฉพาะกับรูปภาพเท่านั้น
C. Web Chat เหมาะกับการที่คนพิมพ์ถาม-ตอบเอง ส่วน API คือช่องทางให้ "ระบบคุยกับระบบ" ฝังความฉลาดของ AI เข้าแอปพลิเคชันได้โดยไม่ต้องมีคนพิมพ์
D. ทั้งสองอย่างทำงานเหมือนกันทุกประการ ต่างกันแค่ชื่อเรียก

### ข้อ 3

B. URL ที่โปรแกรมของเราส่ง request ไปหา AI model
C. พื้นที่ทำงานโดยรวมใน Foundry
D. ไฟล์ที่เก็บผลลัพธ์การประมวลผลของ AI

### ข้อ 4
เหตุใดจึง**ไม่ควร**เขียน API Key ลงในโค้ดโดยตรง (hard-code)?

A. เพราะจะทำให้โปรแกรมทำงานช้าลง
B. เพราะ Python ไม่รองรับการเขียนข้อความยาว ๆ ในโค้ด
C. เพราะเสี่ยงต่อการหลุดรั่วไหล เช่น ตอน commit ขึ้น git ให้คนอื่นเห็นและนำไปใช้โดยไม่ได้รับอนุญาต
D. เพราะ API Key ใช้ได้แค่ครั้งเดียวแล้วหมดอายุทันที

### ข้อ 5

### ข้อ 6

A. ควบคุมความเร็วในการตอบกลับของเซิร์ฟเวอร์
B. ควบคุมจำนวนภาษาที่ AI รองรับ
C. ค่ายิ่งสูงยิ่งทำให้คำตอบสร้างสรรค์/หลากหลายมากขึ้น ค่ายิ่งต่ำยิ่งทำให้คำตอบตรงไปตรงมา คาดเดาได้มากขึ้น
D. ควบคุมขนาดไฟล์ผลลัพธ์ที่ AI ส่งกลับมา

### ข้อ 7
โครงสร้าง Prompt ที่ดีตามที่แนะนำในคอร์สนี้ ควรระบุองค์ประกอบใดบ้าง?

A. แค่คำถามสั้น ๆ ก็เพียงพอแล้ว ยิ่งสั้นยิ่งดี
B. Role, Task, Context, Rules, Output Format และ Input

### ข้อ 8
"Few-shot Prompting" หมายถึงเทคนิคใด?

A. การจำกัดจำนวนคำตอบของ AI ให้สั้นที่สุด
B. การให้ตัวอย่าง (examples) ประกอบไปกับคำสั่ง เพื่อให้ AI ทำงานได้แม่นยำขึ้น โดยเฉพาะงานที่มีคำศัพท์เฉพาะทาง
C. การยิง request ไปหา AI พร้อมกันหลาย ๆ ครั้ง
D. การตั้งค่า temperature ให้เท่ากับ 0 เสมอ

### ข้อ 9
เมื่อให้ AI ตอบกลับมาเป็นข้อความในรูปแบบ JSON การจะนำผลลัพธ์นั้นไปใช้งานต่อในโปรแกรม Python (เช่นดึงค่า field ใดค่าหนึ่ง) ต้องทำอย่างไร?

A. ใช้ได้ทันทีโดยไม่ต้องแปลงค่าใด ๆ
B. แปลง JSON string ให้เป็น Python dict ก่อน (เช่นด้วย `json.loads()`) แล้วจึงเข้าถึงแต่ละ field ได้
C. ต้องแปลงเป็นไฟล์ Excel ก่อนเสมอ
D. ต้องส่งคำตอบนั้นกลับไปให้ AI แปลงให้อีกครั้ง

### ข้อ 10
หลักการ **Human-in-the-Loop** ในการนำ AI มาใช้กับงานจริง (เช่น งานโรงงาน) หมายถึงอะไร?

A. ให้ AI ตัดสินใจและบันทึกข้อมูลเข้าระบบเองทั้งหมด 100% โดยไม่ต้องมีคนตรวจสอบ
B. ให้ AI วิเคราะห์/กรอกข้อมูลให้ก่อน แล้วให้พนักงานตรวจทาน แก้ไข และกดยืนยันก่อนบันทึกจริง
C. ห้ามใช้ AI กับงานที่เกี่ยวข้องกับคนโดยเด็ดขาด
D. ให้คนทำงานทุกขั้นตอนแทน AI ทั้งหมด
