# Lab 2 - Prompt to JSON

## Goal

ฝึกเขียน Prompt ให้ AI ตอบกลับเป็น JSON ที่สามารถนำไปใช้ต่อในระบบงานได้

## What You Will Learn

- Prompt structure
- Output format control
- JSON response
- การสั่งให้ AI ไม่เดาข้อมูลที่ไม่มี

## Run

```bash
python workshops/lab-02-prompt-to-json/starter.py
```

## Challenge

ลองเปลี่ยน `issue_report` แล้วดูว่า JSON output เปลี่ยนอย่างไร
