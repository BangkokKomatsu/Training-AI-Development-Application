# Lab 3 - Factory Issue Analyzer & Web UI

ในแลปนี้ เราจะขยายผลจากการเรียก API และการรับค่า JSON มาสร้างเป็นหน้าเว็บแอปพลิเคชันอย่างง่ายด้วย **Streamlit** ซึ่งจะช่วยให้ผู้ใช้ (User) ใช้งานระบบวิเคราะห์ปัญหาโรงงานได้ง่ายขึ้น โดยมี UI ที่จับต้องได้ ไม่ต้องพิมพ์ผ่าน Terminal

## เป้าหมายของ Lab

1. ประยุกต์ใช้ AI ในการวิเคราะห์และแยกแยะปัญหาหน้างาน (เช่น ปัญหาเครื่องจักรขัดข้อง, ปัญหาความปลอดภัย, หรือปัญหาคุณภาพ QA/QC)
2. นำผลลัพธ์ที่เป็น JSON จาก AI มาแสดงผลแยกส่วนบนหน้าเว็บ (Dynamic UI) เช่น ดึงคำเตือนมาใส่ในการ์ดสีแดง ดึงหมวดหมู่ปัญหามาใส่ในการ์ดสีฟ้า
3. เรียนรู้วิธีรันแอปพลิเคชัน Streamlit เบื้องต้น

## โครงสร้างไฟล์ในโฟลเดอร์นี้

- `starter.py` - สคริปต์พื้นฐานสำหรับวิเคราะห์ปัญหาผ่าน Terminal
- `solution.py` - สคริปต์เฉลยที่มีการเพิ่มเงื่อนไข Routing ลอจิกหลังจากได้ข้อมูลจาก AI
- `app_streamlit.py` - **(ไฮไลต์)** สคริปต์หน้าเว็บ Streamlit เต็มรูปแบบ ผู้เรียนจะได้ลองแก้หน้าตาส่วนนี้ด้วยตัวเอง

## วิธีการรัน

### รันสคริปต์แบบธรรมดา (Terminal)
```bash
python workshops/lab-03-factory-issue-analyzer/starter.py
```

### รันหน้าเว็บแอปพลิเคชัน (Streamlit)
```bash
streamlit run workshops/lab-03-factory-issue-analyzer/app_streamlit.py
```
*(เมื่อรันแล้ว หน้าเว็บจะเด้งขึ้นมาใน Browser อัตโนมัติ หรือสามารถกดลิงก์ `Local URL` ได้)*

## กิจกรรมท้าทาย (Challenge)

1. **เปลี่ยนสีการ์ดแจ้งเตือน:** ลองแก้ไขโค้ด `app_streamlit.py` หาก Priority คือ "Medium" ลองบังคับให้โชว์เป็นสีส้ม (`st.warning`) หรือถ้าเป็น "Low" เป็นสีเขียว (`st.success`)
2. **เพิ่มข้อมูลใน JSON:** ลองเข้าไปแก้ Prompt ใน `app_streamlit.py` ให้ AI เพิ่มฟิลด์ใหม่ เช่น `department_responsible` (แผนกที่รับผิดชอบ) แล้วนำมาแสดงใน UI
