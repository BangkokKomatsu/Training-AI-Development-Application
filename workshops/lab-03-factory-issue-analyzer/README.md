# Lab 3 - Factory Issue Analyzer & Web UI

ในแลปนี้ เราจะขยายผลจากการเรียก API และการรับค่า JSON มาสร้างเป็นหน้าเว็บแอปพลิเคชันอย่างง่ายด้วย **Streamlit** ซึ่งจะช่วยให้ผู้ใช้ (User) ใช้งานระบบวิเคราะห์ปัญหาโรงงานได้ง่ายขึ้น โดยมี UI ที่จับต้องได้ ไม่ต้องพิมพ์ผ่าน Terminal

## เป้าหมายของ Lab

1. ประยุกต์ใช้ AI ในการวิเคราะห์และแยกแยะปัญหาหน้างาน (เช่น ปัญหาเครื่องจักรขัดข้อง, ปัญหาความปลอดภัย, หรือปัญหาคุณภาพ QA/QC)
2. ฝึกเขียนกฎ (Rules) ของ prompt เอง เพื่อให้ AI ส่ง field เพิ่มเติมกลับมา (ต่อยอดจาก Lab 2)
3. นำผลลัพธ์ที่เป็น JSON จาก AI มาแสดงผลแยกส่วนบนหน้าเว็บ (Dynamic UI) เช่น ดึงคำเตือนมาใส่ในการ์ดสีแดง ดึงหมวดหมู่ปัญหามาใส่ในการ์ดสีฟ้า
4. เรียนรู้วิธีรันแอปพลิเคชัน Streamlit เบื้องต้น

## โครงสร้างไฟล์ในโฟลเดอร์นี้

- `starter.py` - สคริปต์พื้นฐานสำหรับวิเคราะห์ปัญหาผ่าน Terminal **มี TODO 2 จุดให้ลองเติมเอง** (ดูหัวข้อ "กิจกรรมท้าทาย" ด้านล่าง)
- `solution.py` - สคริปต์เฉลยที่มีการเพิ่มเงื่อนไข Routing ลอจิกหลังจากได้ข้อมูลจาก AI
- `app_streamlit.py` - **(ไฮไลต์)** สคริปต์หน้าเว็บ Streamlit เต็มรูปแบบ ผู้เรียนจะได้ลองแก้หน้าตาส่วนนี้ด้วยตัวเอง

## วิธีการรัน

### รันสคริปต์แบบธรรมดา (Terminal)
```bash
python workshops/lab-03-factory-issue-analyzer/starter.py
```

### รันหน้าเว็บแอปพลิเคชัน (Streamlit)
```bash
streamlit run workshops/lab-03-factory-issue-analyzer/app_streamlit.py
```
*(เมื่อรันแล้ว หน้าเว็บจะเด้งขึ้นมาใน Browser อัตโนมัติ หรือสามารถกดลิงก์ `Local URL` ได้)*

## กิจกรรมท้าทาย (Challenge)

1. **เขียนกฎ Prompt เอง (TODO 1-2 ใน `starter.py`):** ในฟังก์ชัน prompt ของ `starter.py` แทนที่บรรทัด `[TODO 1: ...]` และ `[TODO 2: ...]` ด้วยกฎจริง:
   - กฎเรื่องแนะนำการดำเนินการเร่งด่วนและเครื่องมือที่ต้องเตรียม
   - กฎเรื่องร่างข้อความเตือนด้านความปลอดภัยสั้นๆ เป็นภาษาไทย

   แล้วเพิ่มชื่อ field ใหม่ 3 ตัวต่อท้ายบรรทัด `summary, category, priority` ด้วย -> `recommended_action, tools_needed, safety_warning` จากนั้นเพิ่มบรรทัด `print(...)` เพื่อแสดงค่าของ field ใหม่เหล่านี้ต่อจาก `Summary` (ใบ้: ดูตัวอย่างได้จาก `solution.py` หรือ `app_streamlit.py`)
2. **เปลี่ยนสีการ์ดแจ้งเตือน:** ลองแก้ไขโค้ด `app_streamlit.py` หาก Priority คือ "Medium" ลองบังคับให้โชว์เป็นสีส้ม (`st.warning`) หรือถ้าเป็น "Low" เป็นสีเขียว (`st.success`)
3. **เพิ่มข้อมูลใน JSON:** ลองเข้าไปแก้ Prompt ใน `app_streamlit.py` ให้ AI เพิ่มฟิลด์ใหม่ เช่น `department_responsible` (แผนกที่รับผิดชอบ) แล้วนำมาแสดงใน UI
