# Lab 5 - Mini Challenge

## Goal

ให้ผู้เรียนออกแบบ Use Case และ Prompt ของตนเอง แล้วทดลองเรียก AI API

## Choose One Use Case

1. Supplier Issue Analyzer
2. IT Ticket Classifier
3. Document Completeness Checker
4. Email Draft Generator
5. Meeting Note to Action Plan

## Task

แก้ไขไฟล์ `starter.py` โดยกำหนด:

- `use_case_name`
- `input_text`
- `prompt`
- output fields ที่ต้องการ

## Run

```bash
python workshops/lab-05-mini-challenge/starter.py
```

## Presentation

สรุป 3 ข้อ:

1. Use Case คืออะไร
2. AI ช่วยอะไร
3. Output เอาไปใช้ต่ออย่างไร
