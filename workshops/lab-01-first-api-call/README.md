# Lab 1 - My First AI API Call

## Goal

ให้ผู้เรียนเรียก AI Model ผ่าน Microsoft Foundry ได้สำเร็จครั้งแรกด้วย VS Code + Python

## What You Will Learn

- อ่านค่า API Key และ Endpoint จาก `.env`
- สร้าง client สำหรับเรียก AI API
- ส่ง prompt ไปยัง model
- แสดง response ที่ได้กลับมา

## Steps

1. เปิด VS Code
2. เปิด terminal
3. ตรวจสอบว่า virtual environment เปิดอยู่
4. รันคำสั่ง

```bash
python workshops/lab-01-first-api-call/starter.py
```

## Expected Output

AI ควรตอบข้อความสั้น ๆ เพื่ออธิบายว่า API Key คืออะไร
