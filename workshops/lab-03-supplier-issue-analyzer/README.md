# Lab 3 - Supplier Issue Analyzer

## Goal

สร้าง Mini AI Agent Prototype ที่ช่วยวิเคราะห์ปัญหา Supplier

## Input

ข้อความแจ้งปัญหาจาก Supplier

## Output

AI จะวิเคราะห์และตอบกลับเป็น JSON ที่ประกอบด้วย:

- summary
- category
- priority
- missing_information
- recommended_action
- email_reply

## Run

```bash
python workshops/lab-03-supplier-issue-analyzer/starter.py
```
