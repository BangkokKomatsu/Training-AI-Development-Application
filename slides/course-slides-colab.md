## คำศัพท์ 4 คำที่ต้องรู้

| คำ | เปรียบเทียบง่าย ๆ |

| **Endpoint** | ที่อยู่ของ AI (เหมือนที่อยู่ตู้ไปรษณีย์) |

## Token คืออะไร (แบบสั้น ๆ พอ)

Token = หน่วยย่อยของข้อความที่ AI ใช้ประมวลผล (ทั้งที่เราส่งเข้า และที่ AI ตอบกลับ)

```text
Token ที่ส่งเข้า + Token ที่ตอบกลับ = ค่าใช้จ่าย
```

**ที่ต้องจำมีแค่:** Prompt ที่ **กระชับ ชัดเจน** = ประหยัดและเร็วกว่า

## Lab 1 — คุยกับ AI ครั้งแรกผ่านโค้ด 🎉

**แนวคิด:** โปรแกรมส่งข้อความไปที่ AI แล้วรับคำตอบกลับมา = หัวใจของทุก AI App

```python
# ✏️ แก้ได้ตรงนี้จุดเดียว
MY_QUESTION = "ช่วยแนะนำวิธีดูแลมอเตอร์ปั๊มน้ำ 3 ข้อสั้น ๆ"

response = client.chat.completions.create(
    model=deployment_name,
    messages=[
        {"role": "system", "content": "ตอบเป็นภาษาไทย"},
        {"role": "user", "content": MY_QUESTION},
    ],
)
print(response.choices[0].message.content)
```

👉 **ลองเปลี่ยน `MY_QUESTION` เป็นคำถามของคุณ แล้วกด Run**

# ส่วนที่ 5
## Prompt Engineering & JSON

---

## Prompt ที่ดีมีโครงสร้าง

```text
Role:          ให้ AI สวมบทบาทอะไร   (เช่น ผู้ช่วยวิเคราะห์ปัญหาโรงงาน)
Task:          ให้ทำอะไร            (เช่น วิเคราะห์และจัดหมวดหมู่)
Rules:         กติกา / ข้อห้าม       (เช่น ห้ามเดาข้อมูลที่ไม่มี)
Output Format: ตอบกลับรูปแบบไหน      (เช่น JSON)
Input:         ข้อมูลดิบที่ให้วิเคราะห์
```

**สูตรจำง่าย:** *บทบาท + งาน + กติกา + รูปแบบคำตอบ*

---

## Few-Shot: สอน AI ด้วย "ตัวอย่าง"

งานโรงงานมีศัพท์เฉพาะ — บางทีอธิบายด้วยกฎอย่างเดียวไม่พอ **ให้ตัวอย่างไปด้วยจะแม่นขึ้นมาก**

**ไม่มีตัวอย่าง (Zero-Shot):**
*"จัดหมวดหมู่: ปั๊มลมมีน้ำมันรั่ว"*

**มีตัวอย่าง (Few-Shot):**
*"ปั๊มลมมีน้ำมันรั่ว → Mechanical*
*เซ็นเซอร์หน้าจอไม่ติด → Electrical*
*สายพานมอเตอร์ขาด → ???"*

---

## ทำไมต้องให้ AI ตอบเป็น JSON

**JSON** = รูปแบบที่ **โปรแกรมอ่านต่อได้ทันที** → เอาไปทำการ์ดสี ใส่ Excel ต่อได้ง่าย

```python
response = client.chat.completions.create(
    model=deployment_name,
    messages=[ ... ],
    response_format={ "type": "json_object" },   # 👈 บังคับให้ตอบเป็น JSON
)
```

> 💡 **หมายเหตุ:** รุ่น `gpt-5-mini` คุมความแม่นยำด้วย **Prompt ที่ชัด + JSON mode** (ไม่ต้องตั้ง `temperature` — รุ่นนี้ปรับไม่ได้ และไม่จำเป็น)

## Lab 2 — ให้ AI ตอบเป็น JSON

```python
# ✏️ แก้ได้ตรงนี้จุดเดียว
ISSUE_TEXT = "มอเตอร์ปั๊มน้ำไลน์ 2 มีเสียงดังและมีควันที่ขั้วต่อสายไฟ"

AI จะแยกออกมาเป็นช่อง ๆ ให้:

🚨 ความเร่งด่วนสูง — ควรแจ้งหัวหน้างานทันที

## ทำ 1,000 แถวรวดเดียว + กันโปรแกรมพัง

```
