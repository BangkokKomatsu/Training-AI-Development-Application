# 03 - Token Basics

## Token คืออะไร

Token คือหน่วยย่อยของข้อความที่ AI ใช้ในการประมวลผล ทั้งข้อความที่เราส่งเข้าไปและคำตอบที่ AI สร้างกลับมา

```text
Input Tokens + Output Tokens = Total Usage
```

---

## ทำไมต้องเข้าใจ Token

Token มีผลต่อ:

- ค่าใช้จ่าย
- ความเร็วในการตอบ
- ข้อจำกัดความยาวของข้อมูลที่ส่งเข้า model
- การออกแบบ prompt ให้กระชับและชัดเจน

---

## ตัวอย่าง

Prompt สั้น:

```text
Summarize this issue.
```

Prompt ที่ดีขึ้น:

```text
Summarize this factory issue in 3 bullet points. Include problem, impact, missing information, and next action.
```

Prompt ที่ยาวขึ้นอาจให้ผลลัพธ์ดีขึ้น แต่ใช้ token มากขึ้น ผู้เรียนควรฝึกเขียน prompt ให้สมดุลระหว่างความชัดเจนและความกระชับ

---

## การคำนวณค่าใช้จ่ายเบื้องต้น (Token Cost Estimation)

ราคาของการเรียกใช้ API จะแปรผันตามโมเดล (Model) ที่เลือกใช้ โดยปกติแล้ว:
- **Input Tokens:** ราคาของการส่งข้อความเข้าไปประมวลผล (มักจะถูกกว่า)
- **Output Tokens:** ราคาของการที่ AI สร้างข้อความตอบกลับ (มักจะแพงกว่า)

**ข้อควรระวังสำหรับภาษาไทย:**
ภาษาไทยมักจะใช้ Token มากกว่าภาษาอังกฤษ (1 Token ≈ 0.75 คำภาษาอังกฤษ แต่สำหรับภาษาไทยอาจจะ 1-3 Token ต่อ 1 ตัวอักษร ขึ้นอยู่กับเวอร์ชันของ Tokenizer)

*ตัวอย่างการประมาณค่าใช้จ่าย:* หากรันไฟล์ Excel 1,000 แถว แถวละ 200 Tokens = 200,000 Tokens การคำนวณค่าใช้จ่ายล่วงหน้าจะช่วยให้คุมงบประมาณในโรงงานได้

---

## ข้อจำกัดการเรียกใช้งาน (Rate Limits)

เมื่อนำโปรแกรมต้นแบบไปใช้จริง (เช่น การอ่านและประมวลผล Excel ทีละหลายบรรทัดต่อเนื่องกัน) คุณอาจเจอกับข้อผิดพลาด `429 Too Many Requests` ซึ่งเกิดจาก **Rate Limit**

- **RPM (Requests Per Minute):** จำนวนครั้งที่ยิง API ได้ต่อนาที
- **TPM (Tokens Per Minute):** จำนวน Token สูงสุดที่ประมวลผลได้ต่อนาที

**วิธีแก้ปัญหาเบื้องต้น:**
ในการเขียนโปรแกรมแบบวนลูป (Batch Processing) ควรใส่คำสั่งหน่วงเวลา เช่น `time.sleep(1)` ระหว่างการประมวลผลแต่ละบรรทัด เพื่อป้องกันการชน Rate Limit
